# Command reference

_Generated by `tools/gen_docs.py` from the code - 149 commands (228 names incl. aliases)._

Every command works with any of the prefixes `/ ! . ;` (e.g. `/ban`, `!ban`, `;ban`). Identify users by **reply**, **@username**, **numeric ID**, **t.me link** or **mention**.

Durations accept `s m h d w M y` or words: `/ban @user 3d 2h 4m reason`, `/mute @user 30 minutes`.

Legend: 👑 Founder / co-founder · 👮🏻 Admin · 👷🏻 Moderator · 👥 Everyone · 🔰 Pro (free here) · 🛠 Bot developer
