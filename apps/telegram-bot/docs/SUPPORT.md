# Support

There is no ticket system. The **💬 Support** button (and `/support`) shows three buttons:
**🌐 Engganyo.com Support** · **✉️ Email Us** · **✈️ Telegram Chat** (t.me/Engganyo).

Set them in `.env`: `SUPPORT_URL`, `SUPPORT_EMAIL` (the email button appears once it is set), `SUPPORT_TELEGRAM` (default `Engganyo`).
