# Instructions for AI coding assistants

Start with `docs/PROJECT_CONTEXT.md` (what the project is, structure, owner decisions, how to run and test).
Rules: never commit `.env` or tokens; run all four test files after every change; keep Title Case short button labels;
keep the "one message at a time" behaviour (`guardbot/handlers/rk.py`); restart the bot after code changes.
The build history is kept privately by the owner. Commits are by the owner only: no co-author trailers.
